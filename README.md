## 我们在做什么

我们要从零开始做一个 **Agent 开发** 项目，方式不是先学完再做，而是 **在开发的过程中学习**：
遇到问题就查、就试、就总结，把每一个能跑起来的小功能都真正搞懂。

## 目标

目前的核心目标很朴素，就一句话：

> **做一个能聊天的、有记忆的 Agent。**

拆开来看，就是两件事：

1. **能聊天** —— 可以多轮对话，理解上下文，正常地一来一回。
2. **有记忆** —— 能记住之前说过的话、做过的事，而不是每次对话都从零开始。

## 学习方式

- **小步迭代**：一次只加一个小能力，加完就运行、验证、复盘。
- **先跑通，再理解**：先让代码能work，再回头弄明白它为什么work。
- **记录过程**：把踩过的坑、想通的点写进这个 README，方便回看。

## 路线图（暂定）

- [ ] 阶段 1：跑通最基础的一次对话（把「聊天」这件事做出来）
- [ ] 阶段 2：加上上下文，让它能进行多轮对话
- [ ] 阶段 3：引入记忆，让它能记住以前聊过的内容
- [ ] 阶段 4：让记忆跨会话保存，形成真正的「长期记忆」
- [ ] 阶段 5：持续优化 —— 记忆的检索、取舍与更新

> 目标不追求一步到位，先能跑，再变好。
